# 🔐 DevSecOps Engineering

> Automating delivery, securing pipelines, and building reliable infrastructure.

---

## 🎯 Responsibilities

- Design and maintain CI/CD pipelines for automated build, test, and deployment
- Integrate security practices into every stage of the software delivery lifecycle
- Manage infrastructure as code (Terraform, Ansible, Crossplane)
- Implement and maintain container orchestration (Kubernetes, Docker)
- Set up monitoring, alerting, and observability for applications and infrastructure
- Conduct security assessments: SAST, DAST, SCA, vulnerability scanning
- Manage cloud infrastructure and ensure cost optimization
- Automate compliance checks and enforce security policies
- Incident response and production support
