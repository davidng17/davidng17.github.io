# 🔐 DSO — Interview Prep Plan

> 8-week preparation for DevSecOps engineering interviews.

---

## 📅 Schedule

### Week 1-2: CI/CD & IaC Foundations

- [ ] CI/CD pipeline design: stages, gates, artifact management
- [ ] Terraform: modules, state management, workspaces, best practices
- [ ] Ansible: playbooks, roles, inventory, idempotency
- [ ] Git branching models: GitFlow, trunk-based development

### Week 3-4: Containers & Orchestration

- [ ] Docker: multi-stage builds, image security, networking
- [ ] Kubernetes: pods, services, deployments, ingress, RBAC
- [ ] Helm charts and Kustomize
- [ ] GitOps with ArgoCD: sync strategies, app-of-apps pattern

### Week 5-6: Security & Monitoring

- [ ] Security testing: SAST, DAST, SCA integration in pipelines
- [ ] Cloud security: IAM policies, network segmentation, encryption
- [ ] Monitoring stack: Prometheus, Grafana, alerting rules
- [ ] Logging: ELK/EFK stack, structured logging, log aggregation
- [ ] Compliance: PCI DSS, ISO 27001, SOC 2 basics

### Week 7-8: Networking & Practice

- [ ] Networking: DNS, load balancing (L4/L7), TLS/mTLS, VPN
- [ ] Incident response: runbooks, post-mortems, SLI/SLO/SLA
- [ ] Practice scenario-based questions (outage debugging, pipeline design)
- [ ] Prepare case studies from past projects

---

## 🎤 Interview Format (Expected)

| Round | Focus | What to Expect |
|-------|-------|----------------|
| 1 | Scenario-based | Given a system/requirement, design the deployment pipeline and infrastructure |
| 2 | Troubleshooting | Debug production issues, explain investigation approach |
| 3 | Security focus | How do you secure the pipeline, infrastructure, and application? |

---

## 🎯 Key Focus Areas

> **Priority topics** — prepare these first:

- ⭐ Pipeline design and automation philosophy
- ⭐ Infrastructure as Code patterns and state management
- ⭐ Container security and Kubernetes operations
- ⭐ Monitoring, alerting, and incident response
- Network architecture and security
- Cloud services and cost optimization
- Compliance and security governance
