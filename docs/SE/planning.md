# 💻 SE — Interview Prep Plan

> 8-week focused preparation for backend engineering interviews.

---

## 📅 Schedule

### Week 1-2: Core Java & Spring Boot

- [ ] Java Core: collections, concurrency, multi-threading, memory model
- [ ] Spring Boot: IoC, AOP, Bean lifecycle, auto-configuration
- [ ] Design Patterns: Singleton, Factory, Strategy, Observer, Builder

### Week 3-4: Microservices & APIs

- [ ] RESTful API design: best practices, versioning, error handling
- [ ] API Gateway, service discovery, load balancing
- [ ] Kafka: producers, consumers, partitions, exactly-once semantics
- [ ] Inter-service communication: sync (REST/gRPC) vs async (events)

### Week 5-6: Database & Testing

- [ ] Database: indexing, query optimization, transactions, ACID
- [ ] ORM: JPA/Hibernate, N+1 problem, caching strategies
- [ ] Unit testing: JUnit, Mockito, test doubles
- [ ] Integration testing: TestContainers, test mindset

### Week 7-8: Security & System Design

- [ ] Security: JWT, OAuth2, authentication vs authorization
- [ ] Solution design: draw architecture diagrams, explain trade-offs
- [ ] Code review practices: SOLID, clean code, refactoring
- [ ] DevOps basics: CI/CD, Docker, cloud deployment

---

## 🎤 Interview Format (Expected)

| Round | Language | Focus |
|-------|----------|-------|
| 1 | English (30-45 min) | Projects, microservices, solution design — components, structure, security, DB |
| 2 | Vietnamese (deep dive) | Each topic deeply — mechanisms, principles, when to use, alternatives |
