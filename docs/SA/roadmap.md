# 🏗️ SA — Learning Roadmap

> From design principles to cloud-native architecture mastery.

---

## 1️⃣ Design Principles

- [ ] SOLID, DRY, KISS, YAGNI, Law of Demeter

## 2️⃣ Architecture Styles

- [ ] Monolithic: modular monolith, scaling strategies
- [ ] Microservices: decomposition, communication patterns, data management
- [ ] Event-driven: CQRS, Event Sourcing, Saga pattern
- [ ] Serverless: cloud-agnostic design, cold start, resource isolation
- [ ] Domain-driven design: bounded contexts, aggregates, ubiquitous language

## 3️⃣ Cloud Design Patterns

- [ ] Resilience: Circuit Breaker, Retry, Bulkhead, Throttling
- [ ] Data: CQRS, Event Sourcing, Sharding, Cache-Aside
- [ ] Messaging: Queue-based Load Leveling, Competing Consumers, Pub/Sub
- [ ] Security: Gatekeeper, Valet Key, Federated Identity

## 4️⃣ Cloud Architecture (AWS)

- [ ] Compute: EC2, Lambda, ECS, EKS, Fargate
- [ ] Storage: S3, EBS, EFS, DynamoDB, RDS, Aurora
- [ ] Networking: VPC, ALB/NLB, Route53, CloudFront, API Gateway
- [ ] Integration: SQS, SNS, EventBridge, Step Functions
- [ ] Security: IAM, KMS, Secrets Manager, WAF, Shield

## 5️⃣ API Design

- [ ] REST, GraphQL, gRPC, WebSocket
- [ ] API versioning, pagination, rate limiting
- [ ] API Gateway patterns and governance

## 6️⃣ Security Architecture

- [ ] Authentication: OAuth2, OIDC, SAML, JWT
- [ ] Authorization: RBAC, ABAC, Policy-based
- [ ] Zero Trust architecture
- [ ] Data encryption at rest and in transit

## 7️⃣ Performance & Scalability

- [ ] Caching strategies (CDN, application, database)
- [ ] Horizontal vs vertical scaling
- [ ] Load balancing and auto-scaling
- [ ] Database optimization and read replicas

## 8️⃣ Observability

- [ ] Distributed tracing
- [ ] Centralized logging
- [ ] Metrics and alerting

## 9️⃣ Migration Strategies

- [ ] Strangler Fig pattern
- [ ] Blue-Green, Canary deployments
- [ ] Data migration and dual-write patterns
