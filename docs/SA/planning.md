# 🏗️ SA — Interview Prep Plan

> 8-week preparation for solution architecture interviews.

---

## 📅 Schedule

### Week 1-2: Foundations

- [ ] Review design principles (SOLID, DRY, KISS) and apply to real scenarios
- [ ] Study architecture styles: monolithic, microservices, event-driven, serverless
- [ ] Practice explaining trade-offs between architecture styles

### Week 3-4: Cloud & Patterns

- [ ] Deep dive into AWS Well-Architected Framework (5 pillars)
- [ ] Study cloud design patterns: Circuit Breaker, CQRS, Saga, Strangler Fig
- [ ] Practice designing systems on AWS (compute, storage, networking choices)
- [ ] Draw architecture diagrams for common scenarios (e-commerce, real-time chat, data pipeline)

### Week 5-6: Security & Integration

- [ ] Authentication/Authorization patterns: OAuth2, OIDC, JWT, RBAC vs ABAC
- [ ] API design: REST vs GraphQL vs gRPC, versioning, rate limiting
- [ ] Integration patterns: sync vs async, message queues, event bus
- [ ] Security architecture: encryption, zero trust, network segmentation

### Week 7-8: Practice & Mock

- [ ] System design mock interviews (2-3 per week)
- [ ] Prepare case studies from past projects (problem → approach → outcome)
- [ ] Practice whiteboard architecture sessions
- [ ] Review non-functional requirements: scalability, availability, performance, cost

---

## 🎤 Interview Format (Expected)

| Round | Language | Focus |
|-------|----------|-------|
| 1 | English (30-45 min) | Projects, microservices, solution design — components, structure, security, DB |
| 2 | Vietnamese (deep dive) | Each topic deeply — mechanisms, principles, when to use, alternatives |

---

## 🎯 Key Questions to Prepare

> Think about these for every system you've designed:

- ⭐ Why did you choose X over Y? (technology selection reasoning)
- ⭐ How would you scale this system to 10x/100x traffic?
- ⭐ How do you handle failure scenarios? (resilience patterns)
- ⭐ Walk me through a system you designed end-to-end
- ⭐ How do you ensure security at each layer?
